# 富邦網路銀行資訊系統 (Fubon Online Banking System)

> **課堂模擬專案** | 銘傳大學 資訊工程學系 | 軟體工程導論

---

## 📋 專案簡介

本專案為銘傳大學「軟體工程導論」課程的分組模擬實作，旨在建置一套安全、穩定且功能完整的網路銀行系統。隨著金融服務數位化的快速發展，傳統臨櫃作業已無法滿足使用者對即時性與便利性的需求。本系統透過整合帳戶管理、交易服務、投資理財及跨平台操作等功能，為不同使用者提供完整的金融服務解決方案。

### 🎯 核心目標

- 提供便捷、安全且智能化的網路銀行服務
- 實現資料集中化管理與即時交易處理
- 支援跨平台操作（網頁與行動應用）
- 打造人性化、直覺化的使用介面

## ✨ 系統功能

### 1️⃣ 帳戶管理
- 線上開戶申請
- 線上信用卡申請
- 網路銀行註冊

### 2️⃣ 交易功能
- **帳戶查詢**：餘額、交易紀錄查詢
- **轉帳服務**：支援跨行、同行、預約轉帳（臺幣、外幣）

- **定期存款**：臺幣及外幣定存申請
- **外幣買賣**：線上購買與出售外幣
- **生活繳費**：水電費、稅金、信用卡繳款等

### 3️⃣ 投資理財
- 基金/股票即時申購與贖回
- 網路投保服務
- 貸款申請、繳納與查詢

### 4️⃣ 跨平台服務
- 網頁瀏覽器支援
- 行動應用程式（APP）

## 🏗️ 系統架構

### 系統環境涵蓋角色
- **使用者**：個人客戶（存戶、信用卡戶、貸款戶、理財戶等）
- **銀行核心系統**：提供客戶資料與交易處理
- **金管會**：監管與合規管制
- **支付與稅務機構**：生活繳費與稅務服務支援
- **證券、保險公司**：投資與保險產品串接
- **技術支援**：資安公司與系統維護廠商

### 設計模式

本系統採用 **物件導向設計方法** (Object-Oriented Design)，包含：
- **使用案例圖 (Use Case Diagram)**：明確系統功能與使用者角色
- **循序圖 (Sequence Diagram)**：描述物件間的互動流程
- **類別圖 (Class Diagram)**：定義資料結構與關係
- **狀態圖 (State Diagram)**：呈現物件的狀態轉換與行為

## 🔒 技術亮點

### 安全防護
- Passkeys/FIDO2 身分驗證
- 裝置綁定與動態交易簽章
- 多層式風險驗證機制
- API mTLS + WAF + 速率限制

### 資料一致性
- 全域唯一交易ID機制
- 冪等鍵設計
- ACID 交易台帳
- 補償交易與對帳流程

### 高可用性與災難復原
- 多區域部署架構
- 自動擴展與壓力測試
- 熔斷/降級策略
- 快取/CDN 加速
- RTO ≤ 1小時，RPO ≤ 5分鐘

### 隱私與稽核
- 傳輸/靜態加密
- 細粒度存取控制 (ABAC)
- 不可竄改稽核日誌
- DLP 稽核與操作留痕

## 🚀 快速開始

### 環境需求
- Python 3.9+
- Node.js 18+ (前端開發)
- Docker (容器化部署)
- PostgreSQL 12+ (資料庫)

### 安裝步驟

1. **複製專案**
```bash
git clone <repository-url>
cd fubon-online-banking
```

2. **安裝依賴**
```bash
cd src/backend
pip install -r requirements.txt  # 後端依賴
cd ../frontend
npm install  # 前端依賴
```

3. **配置環境變數**
```bash
cd src/frontend
cp .env.example .env
# 編輯 .env 檔案，設定資料庫連線、API金鑰等
```

4. **啟動開發伺服器**
```bash
python app.py # 後端伺服器
npm start     # 前端開發伺服器
```

訪問 `http://localhost:5173` 查看應用

## 📖 主要使用案例

### 1. 帳戶查詢
**使用者**可透過系統查詢帳戶餘額及歷史交易明細。

### 2. 轉帳交易
**使用者**可將資金轉入其他帳戶，系統自動判斷是否需要高額轉帳審核。

### 3. 線上申請信用卡
**使用者**提交申請後，系統整合身分驗證、徵信與信用評分機制，進行審核評估。

### 4. 生活繳費
**使用者**可透過系統繳納水電費、稅金等日常帳單。

